# Dados Saude Front

Este projeto foi desenvolvido pela turma **INFO3** como parte do **PPI (Projeto de Prática Integrada)**.

A página apresenta alguns dados antropométricos da turma e permite que o visitante informe seus próprios dados para calcular e visualizar:

* **Idade**
* **Altura**
* **Peso**
* **IMC (Índice de Massa Corporal)**
* **TMB (Taxa Metabólica Basal)**
* Comparações com os dados gerais da turma

## Como funciona

Os dados da turma são utilizados como base para apresentar estatísticas gerais. O visitante também pode preencher seus dados no formulário para gerar seus resultados individuais.

A escala de IMC apresenta diferentes faixas de classificação de forma visual, facilitando a interpretação dos resultados.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* XLSX como fonte dos dados da turma

## Observação

Os cálculos apresentados têm finalidade **informativa e acadêmica**, fazendo parte do projeto da turma. Os resultados não substituem uma avaliação profissional.
